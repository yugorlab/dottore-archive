# Dottore Archive

A fan-made research archive dedicated to Il Dottore from Genshin Impact.

The project collects and organizes official material, chronology, character
analysis, relationships, Segments, theories, and audiovisual sources while
clearly separating canon, inference, and speculation.

## Website

https://yugorlab.github.io/dottore-archive/

## Languages

- English
- Russian
- Teyvat Script will be added soon — English transliteration mode

## Status

The archive is actively maintained and expanded as new official information
becomes available.
